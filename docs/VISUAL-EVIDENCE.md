# Public project visual evidence

Current new assets are **illustrations**, not interface screenshots:

- `src/assets/projects/reve-one/architecture.svg`: Vue/TypeScript, Frappe APIs and ERPNext
  records, with the related application workspaces. 1600×900 vector artwork.
- `src/assets/projects/reve-one/legacy-erp.svg`: legacy Fabric Store Stock Entry, Batch/LOT
  and gate-pass relationships, distinct from REVE ONE. 1600×900 vector artwork.

Both were rendered and visually reviewed. They contain no operational records, private
endpoints or authentication data. Homepage cards, captions and lightboxes label them
as illustrations. Existing genuine captures for other projects are retained.

The requested REVE ONE hero, overview, orders, materials and quality development captures
are **not yet published**. The private source captures and presentation script could not
be inspected through the connected remote device. None were copied into this repository.

For any future captures: inspect the actual UI and provenance; remove every unapproved
record, identity, quantity, date, URL and credential irreversibly; retain authentic layout;
review the final full-resolution image; compress into appropriately sized public variants;
use an explicit sanitized-development caption and intrinsic dimensions. Keep original
captures, browser sessions and private sanitation notes outside the public repository.
